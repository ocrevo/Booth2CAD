# 观察协议：先知道图里有什么，再决定怎么建

## 最小输出

每个主要物件都记录：稳定 ID、原图 ROI、可见事实、遮挡、归属、几何类别、关键程度、依据、未确定部分。
ROI 是原图左上为原点的归一化 `[x0,y0,x1,y1]`，不从预览图反向取坐标。
主结构须有“负空间”记录：开口数、开口边界、能否看到后面的展台结构、是否实际露出展厅。

尺寸缺失并不等于结构可以随意补全。把“白色构件看起来连续”和“后台一定存在钢结构连接”分开。
单张图片只约束可见投影；隐藏部分以最小必要设计补全，不描述为已经还原。

## Scope

booth：展台地毯/地台、自有墙体、楣框、展具、产品、图文和专用灯具。
venue：展厅顶棚、公共灯、结构柱、空调和通道地面。
neighbor：相邻展位、别家图文和展具。
unknown：暂时不能判断归属的物件；禁止一边记录 unknown 一边生成。

吊楣上方的支撑线尤其需要核实：可明确属于展台的吊线可以作为专用结构；不能沿着它把整座展馆桁架一起建进去。
渲染灯光不等于场馆灯具几何。世界背景不属于可导出的展台几何。

## 拓扑和造型优先级

P0：整体轮廓、孔洞/开口、主体连接、前后关系、构件数量、主要朝向。
P1：轮廓圆角、厚度、家具尺度、柜台相对位置、屏幕附着面、地毯高度。
P2：可见 Logo、屏幕媒体、产品陈列、孔阵、材质与自有灯光。
P0 未通过，不通过添加 P2 装饰获得“看起来更像”的假进展。

默认清洁客户展示：Logo、文字、广告、人物、尺寸箭头、水印均 exclude，包括屏幕内的人物和文字；承载它们的柜台/屏幕/楣框继续 include。P2 中品牌和广告不属于本次重建义务，屏幕媒体改为中性。产品陈列按任务约定处理，两条对比路线保持一致。

## Mask 与有效区域

reference silhouette 为“可见的展台像素”，不是参考图所有明亮区域。
透过孔洞看到的后方 booth 仍属于整台 mask；看到的 hall 不属于 mask。
单构件 mask 只包含该构件可见部分，不含被其他构件遮住的推测面积。
valid mask 默认覆盖整个原图；仅对不可信边界、外物遮挡和截断区域做明确排除。不可只留下很小的完美区域来提高指标。
必须记录剔除理由和面积比例。人工/视觉标注必须复核；分割模型结果也不是真值。

本包不会自动调用分割模型；当前示例故意不提供伪造的“已审核”mask。

## 对应点和相机

优先使用可清楚对应到 3D 的角点、圆角切点、屏幕角、柱脚和台面基准点。
圆角整体包围盒角点可能根本没有对应的几何顶点；不要把其当成可见尖角。
拟合点应跨多个深度和平面；至少留两个可见点作为不参与优化的检查点。
不能用“AI 补出的另一个视角”当作新增测量证据。

相机先匹配上/下表面关系与投影类型，再考虑焦距。原图没有看到吊楣顶面时，先排查相机高度，不要先把楣头做得异常薄。
机位过高可能让近侧顶梁遮住源图里的屏幕；先验证相机，不能仅因候选遮挡就断言源图顶棚是 L 形，也不能把所有顶棚强套完整闭环。
两种几何假设都能解释单张图时，优先选择与已知尺度及跨视角结构一致的方案，明确推定。
